## 开源范围说明

本仓库是「理堂」的**开源版本**，包含：

- 首页：校园通知聚合（抓取教务处等公开列表页）
- 地图：自绘校园地图（瓦片加载、地点搜索、双击课程定位教室）
- 我的：课表、成绩、绩点、专业排名、培养计划
- 校历、自动更新

本项目为非官方个人学习项目，与上海理工大学及各平台官方无关，不收集、不上传任何用户数据；
所有凭据仅加密保存在本机。如有侵权请联系删除。
